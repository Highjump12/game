# 자동차 부품 깨기 기획서

## 목표

좌우 방향키로 초록색 바를 움직여 망치를 받아치고, 내려오는 자동차의 부품을 부순다.

## 화면과 부품

- 기준 모니터 해상도는 1024 × 768px이다. 흰색 게임 영역의 기본 크기는 960 × 600px이며, 창의 여유 공간에 맞춰 비율을 유지하며 줄어든다.
- 자동차를 옆에서 본 모양으로 배치한다. 부품마다 이름과 남은 내구도를 표시한다. 내구도는 한 번 맞을 때마다 1씩 줄고, 0이 되면 부품이 사라지며 10점을 얻는다.
- 바는 너비 150px, 높이 14px의 초록색 바이며 검은 테두리가 있다. 망치는 금속 머리와 손잡이가 보이게 그리며, 날아가는 동안 회전한다.

| 부품 | 내구도 |
| --- | ---: |
| 앞문 | 1 |
| 보닛 | 2 |
| 뒷문 | 3 |
| 앞바퀴 | 4 |
| 뒷바퀴 | 5 |
| 지붕 | 6 |

## 진행과 조작

1. 스페이스키로 시작하고 좌우 방향키로 바를 움직인다. 망치는 양옆 벽, 천장, 바, 남은 부품에 맞으면 튕긴다.
2. 총 6단계다. 각 단계에서 단계 번호만큼 부품을 부수면 클리어한다. 어떤 부품부터 부술지는 자유다.
3. 단계를 깨고 스페이스키를 누르면 다음 단계로 이동한다. 새 단계에서는 부품과 내구도, 위치, 속도가 초기 상태로 돌아가며 누적 점수는 이어진다.
4. 망치를 놓치거나 남은 부품이 바 높이에 닿으면 실패한다. 스페이스키로 같은 단계를 다시 시작하며, 점수는 해당 단계 시작 전으로 돌아간다.
5. 6단계를 깨면 최종 승리한다. 스페이스키를 누르면 1단계와 0점에서 다시 시작한다.
6. 단계 안에서 시간이 흐르면 망치와 자동차가 점점 빨라진다. 망치는 초당 310px에서 최대 680px, 차는 초당 2px에서 최대 16px까지 빨라진다.
7. 12초마다 약 1.6초 동안 보라색 캐릭터가 지나가며 일부 시야를 가린다. 망치의 움직임에는 영향을 주지 않는다.

## 파일과 실행

`02-bricks` 폴더의 `brick_game.html`을 브라우저에서 연다. 화면 스타일은 `brick_game.css`, 조작과 게임 규칙은 `brick_game.js`에 있다.

## 구현 완료 기준

- [ ] 자동차의 부품 6개와 각 부품의 남은 내구도가 표시된다.
- [ ] 스페이스키로 시작하고 방향키로 기존 초록색 바를 움직일 수 있다. 회전하는 망치가 벽, 바, 부품에 튕긴다.
- [ ] 타격당 내구도가 1 줄고, 0이 된 부품만 사라지며 점수가 10점 증가한다.
- [ ] 1단계 목표는 1개, 2단계는 2개이며, 6단계에서 부품 6개를 모두 부수면 최종 승리한다.
- [ ] 다음 단계로 넘어갈 때 점수가 이어지며, 실패하면 같은 단계에서 시작 점수로 다시 도전할 수 있다.
- [ ] 망치와 자동차가 시간이 지날수록 빨라지며, 방해 캐릭터가 주기적으로 나타난다.
- [ ] 기준 해상도에서 안내와 게임 화면이 스크롤 없이 보인다.
