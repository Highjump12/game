# 기획서: 자기소개 웹페이지

## 누가 쓰나

수업에서 처음 만난 친구들

## 만들 것

가상 인물 밤토리(22세, 대학 2학년 남학생)를 소개하는 한 페이지짜리 웹페이지

## 기능

1. 별명과 한 줄 소개를 표시한다. “안녕, 나는 밤토리야! 산책할 때 들을 노래를 모으는 걸 좋아해.”
2. 좋아하는 것 세 가지를 표시한다.
   - 이어폰을 끼고 저녁 산책하기
   - 친구들과 협동 보드게임 하기
   - 편의점에서 처음 보는 간식 맛보기
3. 눈이 펑펑 내리는 겨울 산 배경에 스키를 타는 밤토리를 일러스트로 그린다.
4. 자기소개와 좋아하는 것 목록 사이에 녹색 페라리 488 피스타 사진과 밤토리의 자동차 취향을 담은 문장을 연한 녹색 영역에 함께 배치한다. “자동차 얘기도 좋아해. 눈길이 가는 차는 녹색 페라리 488 피스타야.” 사진 출처 링크는 문장 아래에 둔다.
5. ‘배경색 바꾸기’ 버튼을 누르면 페이지 바탕색과 겨울 장면의 하늘색이 함께 바뀐다.

## 조건

- 웹페이지의 HTML, CSS, JavaScript는 모두 `index.html` 한 파일에 작성한다.
- 외부 라이브러리, 서버, 데이터베이스를 사용하지 않는다.
- 실명, 연락처, 인물 사진을 넣지 않는다. 자동차 사진은 HTML 안에 포함한다. 스키 장면은 코드로 그린다.

## 완료 기준

- `01-intro/index.html`을 더블클릭하면 브라우저에서 바로 열린다.
- 별명, 한 줄 소개, 좋아하는 것 세 가지가 표시된다.
- 겨울 산 배경에 눈이 내리고 스키를 타는 밤토리가 보인다. 기기의 동작 줄이기 설정이 켜져 있으면 눈이 정지해 보인다.
- 인터넷 연결 없이도 녹색 페라리 488 피스타 사진이 표시된다.
- 넓은 화면에서는 사진과 소개 문장이 나란히 보이고, 화면 너비가 30rem 이하이면 가운데 정렬한 사진 아래에 소개 문장이 표시된다.
- 버튼을 누르면 페이지 바탕색과 하늘색이 바뀐다.
